Karthikeyan S | Personal Portfolio Website
==========================================

Project Overview
----------------
This is my personal portfolio website showcasing my skills, projects, and contact information.
It is built to highlight my Python and Web Development skills and is fully responsive across devices.

Live Demo: https://karthikeyan-s.github.io

Features
--------
- Dark / Light Mode
- Animated Skills & Projects
- Filterable Projects Gallery (Python / Web)
- Smooth Scrolling Navbar
- Mobile Responsive Design
- Hover Effects on Skills & Projects
- Downloadable Resume button

Technologies Used
-----------------
- Frontend: HTML5, CSS3, JavaScript
- Version Control: Git & GitHub
- API Integration: GitHub API (to fetch projects dynamically)
- Design Tools: Figma (optional)

Projects Section
----------------
The portfolio dynamically fetches your GitHub repositories and categorizes them as:

Project Name | Category | Description
-------------|---------|------------
Project1     | Python  | Brief description of your Python project
Project2     | Web     | Brief description of your Web project
Project3     | Python  | Another Python project

(You can customize categories and descriptions in script.js)

Installation
------------
1. Clone the repository:
   git clone https://github.com/EDWIN-CR/karthikeyan-s.github.io.git
2. Open index.html in your browser to view locally.
3. Optional: Customize repoCategories in script.js to categorize your GitHub repos.
